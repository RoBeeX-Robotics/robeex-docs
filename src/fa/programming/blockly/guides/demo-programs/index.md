# 🧩 برنامه‌های نمونه Blockly

با مثال‌های کامل Blockly، مختصات پرواز، رسم شکل‌ها، فهرست‌ها، سنسورها و پردازش تصویر را تمرین کنید. هر راهنما شامل تصویر بلاک‌ها در ویرایشگر، نام برنامه ذخیره‌شده، فایل JSON برنامه و جدول خلاصه پارامترها است.

ابتدا [اجرا یا تکثیر برنامه](./run-or-duplicate.md) و [ساخت اولین برنامه](../making-your-first-program.md) را ببینید. بلاک‌های هر راهنما را مطابق تصویر بسازید یا، اگر برنامه در بخش User Programs برنامه شما موجود است، همان نسخه را باز کنید. فایل JSON یک کپی از فضای کاری ذخیره‌شده است و برنامه JavaScript نیست.

::: info
برنامه‌ها در ویرایشگر بارگذاری و ذخیره شده‌اند و کد تولیدشده آن‌ها با رابط‌های شبیه‌سازی‌شده پرنده، سنسور و دوربین بررسی شده است. این برنامه‌ها آزمایش پرواز نشده‌اند؛ مسیر واقعی و دقت سنسورها هنوز باید روی پرنده بررسی شوند.
:::

واحد مثال‌های پرواز سانتی‌متر است و در پایان فرود انجام می‌شود. خانه مرجع هنگام برخاستن است؛ بازگشت به خانه فقط موقعیت افقی را تغییر می‌دهد، نه ارتفاع یا Yaw. مثال‌های ثابت سنسور و LED دستور برخاستن ندارند و تا فشردن Stop ادامه پیدا می‌کنند. در این مثال‌ها موتورها باید غیرفعال بمانند. برای پردازش تصویر، پیش از اضافه کردن حرکت، مثال‌های ثابت LED را آزمایش کنید.
