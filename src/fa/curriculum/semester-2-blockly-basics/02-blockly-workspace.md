# جلسه ۲: محیط Blockly و نخستین برنامه بدون پرواز

در این جلسه بخش‌های واقعی محیط را پیدا می‌کنید، یک برنامه LED می‌سازید و تفاوت «بلوک کنار پشته» با «بلوک متصل و قابل اجرا» را عملاً می‌بینید. بلوک پروازی هنوز استفاده نمی‌شود.

## در پایان این جلسه می‌توانید

- برنامه جدید را با نام‌گذاری منظم بسازید؛
- جعبه ابزار، فضای کار، رویداد آغاز، وضعیت اتصال، Run، سطل و منوی برنامه را پیدا کنید؛
- شکل اتصال «دستور» و «مقدار» را از هم تشخیص دهید؛
- یک برنامه LED را پیش‌بینی و اجرا کنید؛
- بلوک آویزان را پیدا، حذف و نسخه اصلاح‌شده را جدا ذخیره کنید.

::: teacher آماده‌سازی پیش از کلاس
روی همه دستگاه‌ها ورود حساب، نسخه اپ و دسترسی Programming را بررسی کنید. یک RoBeeX با ملخ‌های باز یا حفاظت‌شده برای اجرای LED آماده کنید. دو فایل نمونه داشته باشید: یکی صحیح و یکی با بلوک آویزان. برنامه‌ای با بلوک پرواز نسازید.
:::

## ۱. ورود و نام‌گذاری

1. از صفحه اصلی، **Programming** را باز کنید.
2. در مدیر برنامه‌ها، **New Program** را بزنید.
3. نام را با الگوی `S2-L2-Team03-LED-v1` بنویسید.
4. مطمئن شوید برنامه تازه با نمونه‌های Demo اشتباه نشده است.

| بخش | کار آن | بررسی سریع |

| Toolbox | دسته بلوک‌ها | دسته Lights را باز کنید |

::: teacher تور هدایت‌شده

:::

## ۳. اتصال بلوک‌ها: نزدیکی کافی نیست

یک بلوک دستور باید به پشته فرمان قفل شود. یک بلوک مقدار، داخل ورودی مناسب می‌نشیند. بلوکی که چند پیکسل کنار پشته افتاده اما قفل نشده، اجرا نمی‌شود و ممکن است Run را غیرفعال کند.

1. یک بلوک Lights را بکشید و کنار پشته رها کنید.
2. فاصله کوچک ولی اتصال‌نداشتن را ببینید.
3. آن را جابه‌جا کنید تا صدای/نشانه قفل دیده شود.
4. از بالا به پایین پشته را با صدای بلند بخوانید.

::: teacher نکته مربی — سؤال نوع بلوک
بپرسید «این قطعه یک کار انجام می‌دهد یا یک مقدار تولید می‌کند؟» شکل جای اتصال سرنخ نوع است. در این سطح کافی است هنرجو دستور و مقدار را از هم جدا کند.
:::

## ۴. نخستین برنامه: یک بازخورد LED

هدف: بعد از Run، LED به یک رنگ مشخص و روشنایی متوسط برود.

1. دسته **Lights** را باز کنید.
2. بلوک تنظیم رنگ RGB یا روشنایی موجود در نسخه خود را انتخاب کنید.
3. آن را زیر بلوک شروع قفل کنید.
4. رنگ و روشنایی را مقداردهی کنید.
5. پیش‌بینی را بنویسید: کدام LED، چه رنگ و چه زمانی؟
6. فضای کاری را برای بلوک جدا بررسی کنید.
7. روی RoBeeX زمینی، پس از تأیید مربی Run را بزنید.
8. نتیجه واقعی را کنار پیش‌بینی بنویسید.

::: teacher قبل از Run

:::

## ۵. نسخه دوم و خطای بلوک آویزان

1. برنامه را Duplicate کنید و نام را به `v2` تغییر دهید.
2. فقط رنگ یا روشنایی را عوض کنید.
3. یک بلوک اضافی را عمداً کنار پشته رها کنید.
4. نشانه خطا یا غیرفعال‌شدن Run را مشاهده کنید.
5. بلوک را متصل یا حذف کنید و دوباره بازبینی کنید.
6. تفاوت v1 و v2 را در یک جمله ثبت کنید.

  <figcaption>بلوک آویزان ممکن است ظاهراً نزدیک برنامه باشد، اما مسیر اجرا به آن نمی‌رسد.</figcaption>

::: teacher روش عیب‌یابی
به‌جای اشاره مستقیم به بلوک، از هنرجو بخواهید با انگشت مسیر را از Start تا آخر دنبال کند. هر بلوکی که در این مسیر نیست باید عمداً حذف، متصل یا توضیح داده شود.
:::

<strong>توقف و بررسی:</strong> اگر در Workspace بلوک پروازی وجود دارد، حتی جدا از پشته، قبل از اتصال به RoBeeX حذف شود.

::: warning
در این جلسه فقط LED اجرا می‌شود. RoBeeX روی سطح ثابت است، موتور غیرفعال می‌ماند و ورود به Manual Control یا استفاده از Flying ممنوع است.
:::

## کوییز نهایی

بدون کمک هم‌گروهی، هفت بخش محیط را نشان دهید، فرق بلوک دستور و مقدار را توضیح دهید و در یک برنامه نمونه، بلوک آویزان را پیدا کنید.

::: teacher معیار قبولی
هنرجو باید دست‌کم شش بخش از هفت بخش را درست نشان دهد، پشته متصل را از بلوک جدا تشخیص دهد و توضیح دهد چرا نسخه v1 نگه داشته می‌شود. اگر فقط با حدس روی دکمه‌ها می‌زند، تور رابط را تکرار کنید.
:::
