# بخش ۲: اپلیکیشن

در پایان این بخش، هنرجو می‌تواند بخش‌های اصلی اپلیکیشن و محل اطلاعات نسخه را پیدا کند.

::: teacher راهنمای بیان مربی
برای کار کردن با RoBeeX، یک اپلیکیشن و نرم‌افزار مخصوص در اختیار داریم که از طریق آن می‌توانیم به ربات متصل شویم و بخش‌های مختلف آن را کنترل کنیم.
بعد از اتصال به RoBeeX، در صفحه‌ی اصلی چند قسمت مهم در اختیار ما قرار می‌گیرد؛ مثل Programming برای برنامه‌نویسی، Manual Control برای کنترل دستی، Settings برای تنظیمات و Gallery برای مشاهده‌ی فایل‌ها و تصاویر.
همچنین از بخش Device Manager می‌توانیم دستگاه RoBeeX را مدیریت و وضعیت اتصال آن را بررسی کنیم.
در ادامه‌ی آموزش، کم‌کم با هر کدام از این قسمت‌ها آشنا می‌شویم و یاد می‌گیریم چطور از آن‌ها استفاده کنیم.
:::

## مشاهده اطلاعات نسخه نرم افزار

::: teacher راهنمای بیان مربی
در بخش Info می‌توانیم اطلاعات مربوط به نسخه‌ی اپلیکیشن RoBeeX را مشاهده کنیم.
در این قسمت، مواردی مثل شماره نسخه نرم‌افزار، اطلاعات Build و تاریخ ساخت نسخه نمایش داده می‌شود.
این اطلاعات زمانی کاربردی هستند که بخواهیم بررسی کنیم اپلیکیشن ما به‌روز است یا هنگام دریافت پشتیبانی فنی، نسخه‌ی دقیق نرم‌افزار را اعلام کنیم.
پس اگر زمانی از شما خواسته شد Version اپلیکیشن RoBeeX را بررسی کنید، کافی است از بخش Settings وارد تب Info شوید.
:::

## پرسش‌های رایج

::: faq آیا هر گوشی می‌تواند RoBeeX را کنترل کند؟

**پاسخ:** گوشی باید با نسخه اپلیکیشن و شرایط اتصال سازگار باشد و کاربر اجازه دسترسی به دستگاه را داشته باشد.
:::

## تمرین

بدون پرواز، محل Programming، Manual Control، Settings، Gallery، Device Manager و Info را پیدا کنید و نسخهٔ اپلیکیشن را ثبت کنید.

## کوییز نهایی

1. برای کنترل دستی و مدیریت دستگاه به کدام بخش می‌روید؟
2. چرا هنگام گزارش مشکل، نسخهٔ اپلیکیشن را ثبت می‌کنیم؟

::: teacher معیار قبولی
کاربرد بخش‌های اصلی روشن باشد و هنرجو بدون فعال‌کردن موتور میان آن‌ها جابه‌جا شود.
:::
